**适合人群**：移动/联通用户为主、需要更大流量配额、预算中等的用户。

T1 系列走国际优化路由，没有专门针对中国大陆的线路优化。延迟相对较高，但价格是三者中最低的，年付套餐最便宜只要 $36.9。
